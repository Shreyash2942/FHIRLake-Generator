# 🧑‍⚕️ FHIRLake Generator – Practitioner Dataset (FHIR R5)

Synthetic **FHIR Practitioner** dataset generator designed for **analytics-ready, HIPAA-safe workforce data**.  
This module generates realistic healthcare provider records using **HL7 FHIR R5**, aligned with the **FHIRLake Generator** architecture.

All data is **fully synthetic** and intended for **non-production use only**.

---

## 📌 Overview

The Practitioner dataset represents **individual healthcare professionals** such as physicians, nurses, and allied providers.

This dataset is commonly used for:
- Provider workforce analytics
- Linking providers to Encounters, Locations, and Organizations
- Staffing, credentialing, and role-based analytics
- Healthcare data engineering pipelines and portfolios

The generator:
- Uses `fhir.resources` (Pydantic FHIR models)
- Uses `Faker` for realistic synthetic values
- Preserves unsupported FHIR fields using **FHIR extensions**
- Produces **FHIR-valid JSON** suitable for data lakes and ETL pipelines

## 🧩 Contract-Preserving Extensions

Some fields defined in dataset contracts may not exist in the installed `fhir.resources` model.

Instead of dropping these fields, the generator **preserves them using FHIR extensions**.

### Example

```
"url": "https://fhirlake.dev/unsupported/qualification.status"
```

This guarantees:
- Dataset contract completeness
- Forward compatibility
- Stable ETL parsing logic
